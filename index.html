Skills this project builds

Server setup

Installing and configuring Windows Server, users, services and networking.

Hardening

Reducing attack surface with firewall rules, patching and least privilege.

Access and identity

Accounts, groups, permissions and directory services, with verification before changes.

Logging and monitoring

Collecting logs, spotting failed logins and acting on alerts.

Backup and recovery

Scheduled backups, restore tests and a written recovery plan.

Incident response

Containing a problem, recording evidence and escalating to the right people.

Networking tools
